## Phase 1 Scope (MVP) Finalized
**Included:**
- Linear rigid body motion (F = ma integration)
- RK4 integration (4 Runge-Kutta stages)
- VECTOR_3D arithmetic (add, subtract, dot, cross, normalize)
- Sphere-sphere collision detection (distance < r1 + r2)
- Impulse-based elastic collision response
- Kinetic and potential energy computation
- Physics world with 50 bodies target
- Gravity application to all bodies
- Body types: static (immovable) and dynamic (affected by forces)

**Deferred to Phase 2:**
- Rotation (quaternions, angular velocity, torque)
- Plane and box collisions
- Spring forces (Hooke's law)
- Spatial hashing acceleration
- Higher-order integration methods
- Constraints (joints, hinges)
- Soft body dynamics
- Damping/friction

## Design Decisions Finalized
- Architecture: Facade pattern (SIMPLE_PHYSICS) hiding engines
- Data: Immutable vectors (functional style), mutable bodies during integration
- Integration: RK4 with error bound ~1e-4 per 100 steps
- Collision: O(n²) narrow-phase only (no broad-phase yet)
- Concurrency: SCOOP-safe via immutable PHYSICS_RESULT objects
- Error handling: Contract-based (no exceptions)
