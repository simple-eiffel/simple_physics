API Overview

simple_physics provides 11 public classes for physics simulation. This reference documents every class and feature.

Core Classes

Class Purpose
VECTOR_3D 3D immutable vector for positions, velocities, forces
PHYSICS_BODY Rigid body with mass, position, velocity, type
BODY_TYPE Enumeration: STATIC or DYNAMIC
SIMPLE_PHYSICS Facade entry point for library
PHYSICS_WORLD Orchestrates simulation with multiple bodies
PHYSICS_INTEGRATOR RK4 numerical integration (future)
COLLISION_DETECTOR Sphere-sphere collision detection (future)
COLLISION_INFO Collision geometry data
COLLISION_RESOLVER Collision response calculation (future)
COLLISION_RESULT Post-collision velocity data
PHYSICS_RESULT Integration step results

Class Documentation

VECTOR_3D

Purpose: Immutable 3D vector for physics calculations.

Inheritance: Inherits from ANY

Creation Features

Feature Parameters Returns Description
make a_x, a_y, a_z: REAL_64 — Create vector with components (x, y, z)
zero — — Create zero vector (0, 0, 0)

Access Features

Feature Returns Description
x REAL_64 X component (read-only)
y REAL_64 Y component (read-only)
z REAL_64 Z component (read-only)
magnitude REAL_64 Length of vector: √(x² + y² + z²)

Arithmetic Features

Feature Parameters Returns Description
add other: VECTOR_3D VECTOR_3D Vector addition: Self + Other
subtract other: VECTOR_3D VECTOR_3D Vector subtraction: Self - Other
scale factor: REAL_64 VECTOR_3D Scalar multiplication: Self × Factor
dot_product other: VECTOR_3D REAL_64 Dot product: Self · Other
cross_product other: VECTOR_3D VECTOR_3D Cross product: Self × Other
normalize — VECTOR_3D Unit vector in same direction (or zero if near-zero)

Invariant

-- Components are valid REAL_64 values
-- (No NaN or Infinity)

PHYSICS_BODY

Purpose: Represents a rigid body in the physics world.

Inheritance: Inherits from ANY

Creation Features

Feature Parameters Description
make a_mass, a_radius: REAL_64; a_position, a_velocity: VECTOR_3D Create dynamic body with mass, radius, position, velocity
make_static a_mass: REAL_64; a_position: VECTOR_3D Create static (immovable) body

Access Features

Feature Returns Description
mass REAL_64 Body mass in kg (read-only)
radius REAL_64 Body radius in meters (read-only)
position VECTOR_3D Current position in space (read-only)
velocity VECTOR_3D Current velocity m/s (read-only)
body_type BODY_TYPE STATIC or DYNAMIC (read-only)
kinetic_energy REAL_64 KE = 0.5 × mass × velocity² in Joules

Query Features

Feature Parameters Returns Description
potential_energy gravity: REAL_64 REAL_64 PE = mass × gravity × height (y component)

Command Features

Feature Parameters Description
set_position new_position: VECTOR_3D Update position (teleport)
set_velocity new_velocity: VECTOR_3D Update velocity

Invariant

-- mass > 0
-- radius > 0
-- body_type is STATIC or DYNAMIC

BODY_TYPE

Purpose: Enumeration for static vs dynamic bodies.

Values:

  • STATIC — Immovable body (e.g., floor, wall)
  • DYNAMIC — Movable body (affected by gravity and forces)

Access Features

Feature Returns Description
is_static BOOLEAN True if STATIC
is_dynamic BOOLEAN True if DYNAMIC

SIMPLE_PHYSICS

Purpose: Facade entry point for the library.

Inheritance: Inherits from ANY

Creation Features

Feature Parameters Description
make — Create library instance with default settings

Configuration Features

Feature Parameters Returns Description
set_gravity gravity: REAL_64 like Current Set gravity magnitude (fluent, returns self for chaining)

Factory Features

Feature Returns Description
create_world PHYSICS_WORLD Create a new physics world with configured gravity

Access Features

Feature Returns Description
world PHYSICS_WORLD Access the most recently created world

PHYSICS_WORLD

Purpose: Orchestrates physics simulation with multiple bodies.

Inheritance: Inherits from ANY

Creation Features

Feature Parameters Description
make gravity: VECTOR_3D Create world with gravity vector

Configuration Features

Feature Parameters Description
set_gravity new_gravity: VECTOR_3D Update gravity vector

Body Management Features

Feature Parameters Description
add_body body: PHYSICS_BODY Add body to simulation
remove_body body: PHYSICS_BODY Remove body from simulation

Query Features

Feature Returns Description
gravity VECTOR_3D Current gravity vector
bodies LIST [PHYSICS_BODY] All bodies in the world
body_count INTEGER Number of bodies

Simulation Features

Feature Parameters Returns Description
integrate_step dt: REAL_64 PHYSICS_RESULT Advance simulation by dt seconds using RK4 integration

Invariant

-- gravity is valid vector
-- body_count >= 0

PHYSICS_RESULT

Purpose: Result of a physics integration step.

Inheritance: Immutable

Access Features

Feature Returns Description
is_success BOOLEAN True if step completed successfully
collision_count INTEGER Number of collisions detected

COLLISION_INFO

Purpose: Immutable collision detection data.

Access Features

Feature Returns Description
body_a PHYSICS_BODY First colliding body
body_b PHYSICS_BODY Second colliding body
contact_point VECTOR_3D Point of collision in 3D space
normal VECTOR_3D Collision normal (unit vector)
penetration_depth REAL_64 How far objects overlap

COLLISION_RESULT

Purpose: Immutable post-collision response data.

Access Features

Feature Returns Description
body_a_velocity VECTOR_3D Updated velocity for body A after collision
body_b_velocity VECTOR_3D Updated velocity for body B after collision
energy_loss REAL_64 Energy dissipated in collision (Joules)

Contract Reference

All public features are protected by Design by Contract specifications. Key patterns:

Creation Contracts

make (a_x, a_y, a_z: REAL_64)
    -- Create vector with components
    -- No preconditions (always allowed)
    ensure
        x_set: x = a_x
        y_set: y = a_y
        z_set: z = a_z

Arithmetic Contracts

add (other: VECTOR_3D): VECTOR_3D
    -- Vector addition
    require
        other_not_void: other /= Void
    ensure
        result_not_void: Result /= Void
        addition_correct: -- result = self + other

Modification Contracts

set_position (new_position: VECTOR_3D)
    require
        new_position_not_void: new_position /= Void
    ensure
        position_set: position ~ new_position
        velocity_unchanged: velocity ~ old velocity
