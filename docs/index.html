Overview

simple_physics is a production-ready physics simulation engine for Eiffel. It provides rigid body dynamics with RK4 integration, sphere collision detection and resolution, and complete Design by Contract specifications for safety-critical applications.

Part of the Simple Eiffel ecosystem—standard libraries for concurrent, safe, and verified Eiffel programming.

Features

  • 3D Vector Mathematics: Immutable vectors with arithmetic, dot/cross products, and normalization
  • Rigid Body Dynamics: Static and dynamic bodies with mass, position, velocity, and energy calculations
  • RK4 Integration: Fourth-order Runge-Kutta numerical integration for accurate time stepping
  • Collision Detection: Sphere-sphere collision detection with contact geometry
  • Collision Resolution: Impulse-based collision response with post-collision velocities
  • Design by Contract: Complete pre/postconditions and invariants for all public interfaces
  • SCOOP Compatible: Concurrent programming support with immutable result types
  • Void-Safe: Full void_safety=all implementation with no null pointer errors
